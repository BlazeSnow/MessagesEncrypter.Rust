# 多语言（规范参照）

> 原版双语实现的记录。重构版改用 fluent-i18n（后端）+ i18next（前端），键命名与校验规则沿用。

## 1. 语言与范围

- 支持语言：简体中文（`zh-Hans`，默认）与英语（`en-US`，回退）。
- 原版两份资源各 **193 键**，一一对应（`Strings/zh-Hans/Resources.resw`、`Strings/en-US/Resources.resw`）。
- **用户可见文本零硬编码**，范围：页面标题、导航、按钮、菜单、标签、占位符、工具提示、对话框标题/正文/按钮、错误/状态/进度/空状态文案、设置项名称与说明、枚举显示名、文件筛选器描述、剪贴板提示、通知文本。
- 日志、调试信息、内部常量不进资源文件，也不得复用为用户可见文本。

## 2. 键命名规律（沿用）

- 控件属性键：`<元素>.<属性>`，如 `EncryptButton.Text`、`PlainTextBox.PlaceholderText`、`RsaKeySizeComboBox.Header`、`DisplayLanguageSettingsCard.Description`。
- 纯字符串键（逻辑层使用）：`MainWindowTitle`、`StatusXxx`、`ErrorXxx`、`XxxDialogTitle`、`XxxDialogPrimaryButtonText`、`DialogOkButtonText`、`DialogCancelButtonText`。
- 前缀分组：`Home*`、`PageTitle*`、`Import*` / `Generate*` / `Change*` / `Unlock*` / `Rename*` / `Delete*`、`Status*`、`Error*`、`KeyStoreIntegrity*`、`DisplayLanguage*`。
- 带参数文案用格式占位符（`{0}`），如 `DefaultPrivateKeyAlias` = `我的密钥 {0}`、`DeleteKeyDialogContent` = `确定要删除“{0}”吗？…`。
- 键名稳定、语义清晰；禁止用实际文案当键名。

## 3. 语言选择

- 设置项三选：`自动` / `简体中文` / `English`，保存于 KV 设置 `DisplayLanguage`（见 [storage.md](./storage.md) §6）。
- `auto`：跟随系统首选语言；`zh-Hans*` / `zh-CN*` / `zh-SG*` 判为中文，其余一律英语；解析失败回退英语。
- 切换语言保存后提示「重启生效」，确认即重启应用。
- 重构版映射：前端 i18next（`zh-Hans` / `en` 资源包 + 语言探测与回退）；后端 fluent-i18n 用于系统侧文案（如通知）。**错误码 → 文案的映射在前端完成**，后端不返回本地化文本。

## 4. 一致性校验（必须自动化）

原版有校验脚本（`Scripts/Verify-LocalizationResources.ps1`），重构版在 CI 中等价实现：

1. 单一语言资源内键不重复。
2. 各语言键集合完全一致（不缺不多）。
3. 每个键的格式占位符集合在所有语言一致（原版检查 `{0}` / `{0,format}` / `{0:fmt}`；i18next 对应 `{{0}}` / `{{name}}`）。

## 5. 交付约定

- zh-Hans 与 en 资源必须同一批更新；漏译由 CI 拦截。
- 实现页面时对照原版资源逐键对齐文案语义（全表见原版 resw，本目录不复制全表）。
